# 🎱 3D 台球：中式八球 + 斯诺克

## 运行

**Windows：直接双击 `start.bat`**，会自动打开浏览器。

或者手动：

```bash
cd Pool
node server.js
```

然后在浏览器打开 http://localhost:3000 （需要 Node 18+，不用 npm install；Three.js 从 CDN 加载）。

> 直接双击 index.html 打不开，因为浏览器禁止 file:// 加载模块，所以需要这个小服务器。

## 操作

| 操作 | 方式 |
|---|---|
| 第一视角 | 点击画面锁定鼠标：移动鼠标转向，上下移动抬头/低头（Shift 微调）；**按住 S 锁定方向，鼠标往后拉、往前推，杆头碰到母球就出杆，推得越快越大力**（可以来回试杆）；Esc 解锁 |
| 俯视瞄准 | 在球台上左键拖动（按住 Shift 微调），或用 ← → |
| 出杆（通用） | 右侧力度条按住往下拉，松手出杆；或按住空格蓄力，松开出杆 |
| 加塞 | 按住 **E** 移动鼠标移动杆头（左右 = 左右塞，前后 = 高低杆），松开保持；也可以在左下角母球图上点选（双击全部归位） |
| 抬杆尾 | 按住 **B**，鼠标往前抬高、往后放低（约 2°~69°）。抬杆 + 侧塞 = 扎杆，母球走弧线 |
| 摆自由球 | 按住 **M** 移动鼠标；或解锁鼠标后直接拖动母球 |
| 视角 | 「第一视角」/「俯视」，V 键切换；右键拖或 ↑↓ 压低/抬起头；滚轮前后 |
| 辅助线 | 关 / 半 / 全，G 键切换 |
| 自由球 | 拖动母球摆位（第一视角下先按 Esc 解锁鼠标；开球犯规只能放开球线后） |

辅助线三档：
- **关**：只看球杆
- **半**：母球路线 + 撞击位置的虚影球，不显示目标球怎么走
- **全**：再加目标球出球方向（黄）、母球分离切线（蓝）、一次库边反弹

## 模式

- **第一次打开会强制进入教学关**（11 步，教会所有按键），完成后才进入主菜单
- 主菜单：单人练习 / 双人对战（需要输入两位玩家的用户名）/ 教学关 / 设置
- **Esc**：菜单（换球杆、辅助线、视角、鼠标灵敏度、音效、按键说明）

## 斯诺克模式

按 WPBSA 官方规则做的 12 尺斯诺克台：

- 台面 3569 × 1778 mm，球径 52.5 mm；开球线距底库 737 mm，D 区半径 292 mm，黑球点距顶库 324 mm
- 袋口：官方模板约 84 mm，这里角袋 116 mm（最窄处约 1.9 个球）、中袋 122 mm（放宽）
- 红球、彩球交替；红球打完后按 黄→绿→棕→蓝→粉→黑 依次清台；彩球自己的点被占时按规则复位
- 犯规至少罚 4 分（目标球或涉及的球分值更高时按更高的算，最多 7 分）
- 犯规后对手可选择：自己打 / 让对方再打；被斗住时自动给自由球（FREE BALL）
- MISS：没先碰到目标球且出杆前没被斗住 → 可以把球摆回原位让对方重打；连续三次 MISS 判负
- 最后一颗黑球打完平分 → 黑球复位决胜
- 赛制：1 局 / 3 局 2 胜 / 5 局 3 胜 / 7 局 4 胜
- 界面：电视转播风格比分条（局分、得分、实时单杆 BREAK 和进球顺序、台面剩余分、分差、需要斗球提示）、犯规 / 自由球 / 破百 / 满分杆横幅
- 彩球阶段以第一颗碰到的彩球作为所选的彩球（自动叫球）

## 球杆避让

母球贴库时自动把击球点提高（加高杆），从库边上方过；母球靠近库边但没贴着、或者杆后面有球挡着时，自动抬杆尾到刚好不穿模的角度。左下角会显示「贴库：自动加高杆」「自动抬杆尾」。

## 代码结构

```
src/physics.js  物理引擎（确定性，前端和以后的服务器共用）
src/rules.js    八球规则判定（纯逻辑，联机时放服务器）
src/aim.js      辅助线计算
src/clearance.js 球杆避让（自动加高杆 / 抬杆尾）
src/cues.js     三种球杆的外观和物理参数
src/tutorial.js 教学关
src/snooker.js  斯诺克规则（犯规、自由球、MISS、复位、局末）
assets/sounds/  真实音效
src/render.js   Three.js 场景：球台、球、球杆、灯光、镜头
src/audio.js    合成音效
src/main.js     主循环、输入、界面
server.js       本地静态服务器（第二阶段加 WebSocket 房间）
```

## 物理参数（physics.js 顶部 `PHYS`）

| 参数 | 值 | 作用 |
|---|---|---|
| muSlide | 0.2 | 台呢滑动摩擦：决定高低杆「吃」多久变成自然滚动 |
| muRoll | 0.014 | 滚动阻力：台呢快慢 |
| spinDecel | 8.5 | 侧旋衰减 |
| eBall | 0.95 | 球与球的弹性 |
| 库边恢复系数 | 0.75 − 0.03×速度（最低 0.5） | 库边弹性：越大反弹越快（在 resolveCushion 里） |
| muCushion | 0.14 | 库边摩擦：塞对反弹角的影响 |
| squirt | 0.035 | 加塞时母球的偏移 |

台面 2540×1270 mm，球径 57.15 mm；中式黑八台的圆弧袋角，角袋口最窄处 106 mm、中袋口 124 mm，都在 `TABLE` 里可改。

## 在线对战

主菜单 →「在线对战」→ 输入用户名：

- **创建房间**：选玩法（中式八球 / 斯诺克 + 赛制），得到 4 位联机码，发给朋友。
- **加入房间**：输入朋友给的联机码。

连接方式（自动选择）：

- **互联网**：浏览器之间 P2P 直连（PeerJS 公共服务器配对，带 STUN/TURN），不用开端口。朋友需要有同一版本的游戏（把整个 Pool 文件夹发给他，用 start.bat 打开）。
- **同一个 WiFi**：朋友不用装，直接打开 `server.js` 启动时显示的 `http://你的IP:3000` 就行（Windows 第一次可能会问防火墙，选允许）。

对战中：

- 房主是玩家 1，先开球；八球再来一局时轮流开球。
- 不是你的回合时固定俯视观战，能看到对手的球杆、加塞和摆母球。
- 每一杆只发送击球参数和出杆前的球位，两边用同一套确定性物理各算一遍，打完再核对一次状态。
- 斯诺克犯规后由被犯规的一方选择；一局结束后由房主开下一局。
- 左上角显示房间号、连接方式、延迟和当前回合。

## 联机思路（下一步）

物理只用加减乘除和开方，同样的输入在任何机器上结果完全一致。所以联机时一杆只需要发送 `{dx, dy, speed, a, b}`：服务器和双方客户端各自模拟，结束后由服务器下发最终球位并用 `rules.js` 判定。
